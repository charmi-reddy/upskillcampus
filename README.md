# Projects


## 1. Turbofan Engine Remaining Useful Life Prediction


### Overview


The first project focuses on **predictive maintenance for turbofan engines**.


Turbofan engines generate sensor measurements and operational data throughout their operating cycles. As an engine approaches failure, changes can occur in its sensor behaviour.


The objective of this project is to use historical engine data to predict the **Remaining Useful Life (RUL)** of an engine, represented as the number of operational cycles remaining before failure.


### Workflow


```text
Turbofan Engine Data
        ↓
Data Preprocessing
        ↓
RUL Target Generation
        ↓
Exploratory Data Analysis
        ↓
Feature Preparation
        ↓
Machine Learning Model
        ↓
RUL Prediction
        ↓
Model Evaluation
```

### Key Work

● Analysed turbofan engine sensor and operational-cycle data.

● Generated Remaining Useful Life targets from engine degradation cycles.

● Performed data preprocessing and exploratory analysis.

● Analysed sensor trends and correlations.

● Developed regression-based Machine Learning models.

● Compared model performance using evaluation metrics.

● Generated RUL predictions for test engine units.

● Visualised actual versus predicted RUL values.

## 2. Mining Process Quality Prediction

### Overview

The second project focuses on quality prediction in an iron ore mining process.

The project uses process measurements from an iron ore flotation plant to predict the percentage of silica in the final iron ore concentrate.

The goal is to understand how different process variables influence the final quality measurement and determine whether Machine Learning can provide useful predictions.

### Workflow
```text

Mining Process Data
        ↓
Data Cleaning
        ↓
Timestamp Processing
        ↓
Exploratory Data Analysis
        ↓
Feature Preparation
        ↓
Regression Models
        ↓
Silica Prediction
        ↓
Model Comparison
        ↓
Evaluation & Analysis
```
### Key Work

```text
● Analysed industrial mining process data.

● Processed time-based measurements.

● Investigated missing values and data quality.

● Performed exploratory data analysis.

● Studied relationships between process variables and silica concentration.

● Developed multiple regression models.

● Compared models with and without the highly correlated iron feature.

● Analysed feature importance.

● Evaluated predictions using regression metrics.

● Performed prediction and residual analysis.
```
